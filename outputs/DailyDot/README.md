# DailyDot

原生 macOS 极简桌面待办。SwiftUI + AppKit，无第三方依赖。最低 macOS 13，推荐 Xcode 16 或更新版本。

## 运行

1. 打开 `DailyDot.xcodeproj`。
2. 选择 DailyDot scheme、My Mac，按 ⌘R。
3. 首次启动时，屏幕右上方出现一个灰色圆点。点击展开，再点收起。拖动圆点可移动位置；展开时也可拖动右上角圆点。
4. 使用菜单 DailyDot → Quit DailyDot 或 ⌘Q 退出。

也可用 Xcode 打开 `Package.swift`，或执行 `swift run DailyDot`。建议使用 Xcode 工程以获得完整的 .app、稳定的应用标识及 Dock 行为。

## 操作

- 左下角 ＋：在列表底部打开输入框并聚焦。
- Enter 保存；Esc 取消；点击输入框之外或切换应用会保存。空白输入不会创建任务。
- 点击复选框切换完成状态，完成项保留原位并显示删除线。
- 悬停任务行时显示垃圾桶，点击立即删除。
- 只有列表滚动，标题和添加按钮固定。
- 收起时仅显示 40pt 纯色圆点，使用 floating 窗口层级；展开为 390 × 550pt 普通层级窗口，可被其他应用遮挡。
- 展开沿圆点向左下方延伸，圆点中心坐标保持不变。为同时保证自由拖动和严格锚定，靠近屏幕左边缘/下边缘时，展开面板可能部分位于屏幕外；拖动右上角圆点即可移回。初始位置选在右上方，正常完整显示。

## 保存与跨日

`UserDefaults` 的 `DailyDot.archive.v1` 保存 Codable JSON，按本地日期 YYYY-MM-DD 归档。新增、完成、删除、跨日均立即写入。历史日期记录保留在数据中，本版不提供历史浏览界面。

每秒检查本地日期，并在应用激活、唤醒、时区变化、任务操作时再次检查。新日期仅复制最近一个已记录日期的未完成项，生成新的任务 ID，不改动旧日期；若多天未启动，最后记录的未完成项仍会带入。完成项只留在原日期。同一天不会重复迁移。

午夜发生切换时，未提交的输入草稿取消，已保存的任务正常迁移。

窗口圆点位置保存在 `DailyDot.position`。启动及显示器配置变化时，将圆点限制在可用屏幕内；原显示器断开时回到主屏。支持多个显示器及 Spaces。拖动圆点可重新定位。

## 结构

- `AppDelegate.swift`：应用生命周期、菜单、日期检查。
- `WindowController.swift`：无边框窗口、窗口层级、拖动、锚点、多屏恢复。
- `TaskStore.swift`：每日归档、跨日迁移、持久化。
- `TodoTask.swift`：任务与归档模型。
- `ContentView.swift`：磨砂背景、任务行、输入与悬停删除。
- `Tests/DailyDotTests`：持久化和跨日逻辑测试。

视觉参考提供的图片：白色磨砂圆角卡片、等宽字体、细线复选框、完成项弱化。功能以需求为准，不包含图片中的分类及筛选标签。圆点颜色在 `DotView.draw` 的 `NSColor(calibratedWhite: 0.48, alpha: 1)` 统一替换。

## 曲线路径调整（当前版本）

实现技术为 AppKit / Core Animation，使用 `CALayer`、`CAKeyframeAnimation`、`CAShapeLayer`，不涉及 CSS、Web Animations API 或第三方动画库。仅修改 `WindowController.toggle()` 内的动画表现，触发、锚点、终点和功能不变。

### 空间曲线

使用真正的三次贝塞尔位置曲线 `B(p) = (1-p)^3 P0 + 3(1-p)^2 p C1 + 3(1-p)p^2 C2 + p^3 P3`。将内容分为 180 个水平分片，采样 121 帧，分别映射左右边缘及上下边界，再计算每个内容分片的位置与尺寸，不再沿直线位移。

参数说明（单位 pt）：源坐标 P0=(x,y)，u=x/390，v=y/550，b=sin(πv)。终点 P3 为源内容按 40/390、40/550 压缩后围绕原圆点中心的坐标。D=P3-P0，向内偏移 I=(1-2u)×46×(0.4+0.6b)。

- C1=(x+0.12Dx+0.65I, y+0.06Dy−18b−22v²)
- C2=(x+0.70Dx+0.35I+30b, y+0.88Dy−22b−12v²)

左右两边有相反的向内偏移，并随高度连续变化，形成轻微内凹的吸入轮廓；内容跟随同一空间映射。没有弹簧或超调。展开沿同一空间曲线反向恢复。

### 节奏、圆角、透明度

- 时长：0.92 秒。
- Core Animation 节奏控制点 `(0.32, 0.08, 0.24, 1)`，对应 `cubic-bezier(0.32, 0.08, 0.24, 1)`：起步较轻，中段加速，结束缓出。
- 圆角遮罩使用相同的空间曲线及节奏。源椭圆圆角半径由 25pt 平滑增长为半宽、半高，再经映射形成最终 40pt 圆形轮廓。
- 透明度在前 18% 几何进度保留，随后用 smoothstep 平滑渐隐，淡出两端斜率为零。透明度、路径、遮罩和尺寸共用相同进度，完全透明后才切回纯色圆点。

验证：Xcode 构建成功。对 121 个进度、181 条横向边界进行几何采样，未发现负尺寸、网格翻折或无效坐标；四角及内容中心均为非直线路径，终点保持原圆点位置。未完成实际桌面播放的视觉核验。
